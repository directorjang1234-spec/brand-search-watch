# 건기식 브랜드 검색 감시

건강기능식품 경쟁 브랜드 18곳의 **네이버 브랜드 검색량**과 **주간 검색추세**를 주기적으로 수집해
한 장으로 정리한 리포트입니다. 사내 AI 교육 2회차 과제(대시보드 제작·배포) 산출물입니다.

**배포 주소** → https://directorjang1234-spec.github.io/brand-search-watch/

## 무엇을 보는가

- **월간 브랜드 검색량** — 네이버 검색광고 키워드도구의 월간 조회수(PC+모바일). 볼륨(후행 지표).
- **주간 검색추세** — 네이버 데이터랩 검색어트렌드로 최근 7일 평균을 직전 4주 평균과 비교. 방향(선행 지표).

두 지표가 갈리는 지점이 핵심입니다. 2026-08-11 집계 기준으로 카테고리 추세 중앙값은 +6%로 반등했지만,
월간 볼륨은 대부분 3주 전보다 낮습니다. 즉 지금의 플러스는 여름 급락분의 **되돌림**이지 아직 성장이 아닙니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 리포트 본체. 외부 의존성 없는 단일 HTML(차트는 인라인 SVG + 바닐라 JS) |

데이터는 수집 파이프라인이 만든 스냅샷을 리포트에 반영하는 방식이며, 이 저장소에는
공개 가능한 형태로 가공한 결과물만 올립니다.

## 한계

브랜드 검색량은 **매출도 점유율도 아닙니다**. 관심의 대리지표입니다.
데이터랩은 비율값 기반이라 절대 검색수가 아닌 상대 변화만 의미가 있고,
저검색 브랜드는 네이버가 값을 가려(마스킹) 정확도가 떨어집니다.
